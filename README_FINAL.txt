SMART FLOOD RELIEF DISTRIBUTION AND RESOURCE ALLOCATION SYSTEM

Files
- main.cpp                 Final C++ implementation
- flood_relief_demo.html   Lightweight browser demonstration
- TEST_REPORT.txt          Build, search, and scenario verification
- demo_output.txt          Output from ./flood --demo

Build
  g++ -std=c++17 -Wall -Wextra -pedantic -o flood main.cpp

Run interactive program
  ./flood

Run integrated test scenario
  ./flood --demo

Web demo
Open flood_relief_demo.html in a modern browser. No server or external package is required.

Project alignment
The implementation follows the proposal's stated methodology: data input and request management, priority handling, route management, resource allocation, unit/system testing, debugging/validation, optimization, and final demonstration. The proposal identifies CO-2 for queue/linked-list structures, CO-3 for searching/sorting, and CO-5 for graph traversal. See proposal pages 1-3 for these requirements and the action plan. The final evaluation includes report submission, seminar presentation and oral examination.
