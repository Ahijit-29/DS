Oral Examination & Viva Defense Cheatsheet (Top Marks Guide)
Q1: Why did you use Dijkstra's Algorithm instead of Breadth-First Search (BFS)?

BFS only finds the shortest path in unweighted graphs where all edges have identical cost. Real road networks have varying physical distances in kilometers (e.g. 100 km vs 190 km). Dijkstra with a min-priority queue guarantees the minimum accumulated travel distance in O((V + E) log V).

Q2: Why use a Max-Heap for camp scheduling instead of sorting an array each time?

Sorting an array requires O(N log N) every time an emergency SOS call arrives. A Binary Max-Heap supports inserting an emergency request in O(log N) and extracting the highest-priority camp in O(log N), which is optimal for real-time disaster streaming.

Q3: What role does Disjoint Set Union (DSU) play?

When multiple bridges collapse simultaneously, camps can become geographically isolated into disconnected graph components. DSU uses union-by-rank and path compression to detect if Depot (node 0) and Camp (node i) share the same root in near O(1) time, triggering amphibious watercraft protocols when severed.
